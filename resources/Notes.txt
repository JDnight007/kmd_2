``` Example of ARM RISC set Assembly
		B	main

hello		DEFB	"Hello World!\n",0

		ALIGN

main		ADRL	R0,hello
		SWI	3

		SWI	2
```

``` Complete example with characters
\t\tB\tmain\n
\n
hello\tDEFB\t"Hello World!\n",0\n
\n
\t\tALIGN\n
\n
main\t\tADRL\tR0,hello\n
\t\tSWI\t3\n
\n
\t\tSWI\t2\0
```

Observation : The basic structure of each line seem to follow : "<branch>? (\t+ <OpCode> \t+ <Operands>?)? \n"

Subsequently breaking down the line produces 0-3 components:
	. 0 : blank line ('\n')
	. 1 : Stand-alone Opcode (Eg. 'ALIGN')   OR   Branch Header (Eg. 'main')
	. 2 : Opcode and Operand (Eg. 'ADD R0,R0,R0') : 'R0,R0,R0' - operand
	. 3 : Branch headed Opcode and Operand (Eg. 'main ADRL R0,hello')
